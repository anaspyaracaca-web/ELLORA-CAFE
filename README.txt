ELLORA CAFE — LUXURY EDITORIAL WEBSITE

GETTING STARTED
Open index.html in a modern web browser. For local development, serve this
folder with any static file server; no build tools, packages, or frameworks
are required.

PROJECT FILES

NOTES
This is a static front-end demonstration. Reservation, contact, and newsletter
forms do not transmit or store submissions. The loyalty card stores its demo
stamp count in localStorage on the current browser and device. Sample addresses,
hours, prices, and testimonials are illustrative, not real business details.
Photographs are loaded from Unsplash URLs, and typefaces from Google Fonts,
so those assets require an internet connection.

The site uses semantic HTML, keyboard-operable controls, responsive layouts,
and reduced-motion preferences. No framework or package installation is needed.
